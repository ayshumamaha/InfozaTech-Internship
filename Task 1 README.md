# To-Do List Application

## Overview
The To-Do List Application is a simple Python program that helps users organize and manage daily tasks. Users can add tasks, view their task list, mark tasks as completed, and delete tasks. The application saves task information in a JSON file.

## Features
- Add new tasks.
- View all tasks and their completion status.
- Mark tasks as completed.
- Delete tasks.
- Save tasks using JSON file storage.
- Validate user inputs and handle invalid menu choices.

## Technologies Used
- Python 3
- JSON
- pathlib

## How to Run
Ensure Python 3 is installed, then run:

```bash
python task1_todo_list.py
```

## Data Storage
Tasks are saved in `tasks.json`, which is created automatically when data is saved.

## Concepts Used
Functions, lists, dictionaries, loops, conditional statements, file handling, JSON, and exception handling.

## Conclusion
This project demonstrates how Python can be used to build a practical task management application with persistent data storage.
