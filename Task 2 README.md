# Rock, Paper, Scissors Game

## Overview
The Rock, Paper, Scissors Game is an interactive Python application in which the user competes against the computer. The computer randomly selects an option, and the program determines the winner based on the game's rules.

## Features
- Play against the computer.
- Generate random computer choices.
- Determine the winner of each round.
- Track player wins, computer wins, and draws.
- Display the final score.
- Exit the game whenever desired.

## Technologies Used
- Python 3
- random module

## How to Run
Ensure Python 3 is installed, then run:

```bash
python task2_rock_paper_scissors.py
```

## Game Rules
- Rock defeats scissors.
- Scissors defeats paper.
- Paper defeats rock.
- Identical choices result in a draw.

## Concepts Used
Randomization, functions, loops, tuples, conditional statements, and score tracking.

## Conclusion
This project demonstrates Python's ability to implement interactive games using random choices and logical decision-making.
