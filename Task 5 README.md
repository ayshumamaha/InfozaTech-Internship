# Contact Book

## Overview
The Contact Book is a Python application designed to store and manage contact information through a command-line interface. Users can create contacts, view saved entries, search for information, update existing details, and delete contacts.

## Features
- Add new contacts.
- View all saved contacts.
- Search by name, phone number, or email address.
- Update contact information.
- Delete contacts.
- Save contacts in a JSON file.
- Validate required fields and handle invalid menu choices.

## Technologies Used
- Python 3
- json
- pathlib

## How to Run

```bash
python task5_contact_book.py
```

## Data Storage
Contact information is stored in `contacts.json`, which is created automatically when data is saved.

## Concepts Used
Functions, lists, dictionaries, string operations, loops, conditional statements, JSON file handling, and exception handling.

## Privacy Considerations
Contact information should be handled responsibly and should not be shared without authorization.

## Conclusion
This project demonstrates how Python can be used to build a contact management system with search, update, delete, and persistent storage features.
