# Password Generator

## Overview
The Password Generator is a Python application that generates passwords according to the user's chosen length and character preferences. It uses Python's `secrets` module to provide security-oriented random generation.

## Features
- Generate passwords between 4 and 128 characters.
- Include uppercase letters.
- Include lowercase letters.
- Include digits.
- Include special symbols.
- Ensure every selected character category is represented.
- Validate password length and character selections.

## Technologies Used
- Python 3
- secrets
- string

## How to Run

```bash
python task4_password_generator.py
```

## Concepts Used
Functions, strings, lists, loops, input validation, and secure randomization.

## Security Considerations
Generated passwords should be kept confidential. Avoid sharing passwords or storing them in unprotected files. Use a trusted password manager when saving passwords.

## Conclusion
This project demonstrates how Python can generate customizable passwords using secure randomization and user-defined requirements.
